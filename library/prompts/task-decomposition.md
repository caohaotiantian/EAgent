# Task decomposition (fragment)

A scaffold for a lead/coordinator persona to break a mission into delegable work.

1. **Restate the goal** in one sentence and its measurable success criteria.
2. **List the unknowns** that block a plan; decide which to resolve by
   investigation before committing.
3. **Decompose** into subtasks that are each independently checkable and small
   enough for one expert to finish without further decomposition.
4. **Map dependencies**: which subtasks are independent (can run in parallel) and
   which must be ordered (a pipeline).
5. **Assign** each subtask to the single most appropriate expert, with enough
   context to work without you.
6. **Choose the pattern**: orchestrator (decompose) / parallel (independent) /
   sequential (ordered) / generator-verifier (quality) / consensus (high-stakes) /
   blackboard (build-on-each-other).
7. **Define done** and stop when the success criteria are met — not before, not
   after.
