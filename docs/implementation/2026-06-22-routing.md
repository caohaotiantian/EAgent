### Design refs (load-bearing facts to honor)

- **Reuse the existing seam, zero kernel change** (design D1): `Agent.model` is
  `public` + mutable (`src/kernel/agent.ts:72`, defaulted `:98`) and the loop
  re-reads `this.model` each turn at request-build (`agent.ts:269`) and for
  `transformContext` (`agent.ts:262`). Do **not** add a hook/field/seam.
- **Hook ordering** (design §5): `turn_start` fires at `agent.ts:180`, *before*
  `streamTurn` at `:182`; `agent_start` at `:162`; `agent_end` at `:247` inside
  the loop's `finally` (so it runs even on error/abort). A `turn_start` handler
  that sets `e.agent.model` is observed by the very request that turn builds.
- **Heuristic constants are pinned defaults, store-overridable** (design D2):
  `HARD_CHAR_LEN = 280`, `HARD_TOOL_RESULT_BYTES = 8192`, and the
  `HARD_KEYWORD_CUES` cue set (`["debug","design","architect","refactor",
  "migrate","optimize","race","deadlock","security","vulnerability","proof",
  "prove","algorithm","concurrent","concurrency"]`), matched **whole-word,
  case-insensitive** (the `microagents` trigger-match shape). A turn is
  `flagship` if any of {latest user text length ≥ `HARD_CHAR_LEN`, any cue
  present, most recent `tool_result` content byte size > `HARD_TOOL_RESULT_BYTES`};
  otherwise `cheap`.
- **Conservative-on-unsure → flagship** (design D2, AC-6): when no trivial signal
  can be evaluated (e.g. absent/empty latest user text) and no LLM mode is
  configured, return **flagship**, never cheap. A wrong call over-spends.
- **Tier map is the SOLE resolution surface** (design D3): a two-key store map
  `{ cheap, flagship }` merged over date-pinned defaults, re-read every turn. The
  guard validates **against this map, not the provider registry** — the registry
  keys by **provider name, not model id** (`registry.ts:73-83`), so there is no
  model-id query to make. A tier whose entry is **missing or not a non-empty
  string** falls back to the captured baseline with an `e.log.warn` (never a
  throw). A *well-formed-but-provider-unknown* id is **not** caught here — that is
  the provider's normal turn error, exactly as for a typo'd `Agent.model` today.
- **Capture/restore** (design D4): capture `e.agent.model` on `agent_start` as
  the baseline (mirrors `cost.ts:203`); restore it on `agent_end` and on disable.
- **Off by default + `EAGENT_ROUTING=off`** (design D6): env `off` short-circuits
  `activate` to `return () => {}` (the `cost.ts:150-152` / `recovery.ts:103`
  pattern). Otherwise enablement is a store flag toggled by `/routing on|off`.
- **Optional sub-call** (design D2/§4): only when `mode === "llm"`. Recursion-safe
  tool-less provider call — `provider.stream({ systemPrompt, messages, tools: [],
  model: e.agent.model, signal })` (the risk-guard shape, `risk-guard.ts:124-132`)
  — parsing a lenient `CHEAP`/`HARD` verdict (model `parseVerdict`,
  `risk-guard.ts:58-68`). **Fails open** to the heuristic, then to flagship; never
  throws. The sub-call runs on the **currently configured** `e.agent.model`, not a
  routed tier (design §3 "No routing of the classifier sub-call itself").
- **Model only, never capabilities** (design D5): never read/grant/deny a
  capability; declare none for the default path.

## 3. Engineering Constraints Index

**House rules (CLAUDE.md):**
- **ESM + NodeNext.** Use `.js` import specifiers even for `.ts` sources
  (e.g. `import type { ExtensionAPI } from "../kernel/extension.js";`). Required
  by `module: NodeNext` + `verbatimModuleSyntax`.
- **Strict TypeScript.** `strict`, `noUncheckedIndexedAccess`,
  `noImplicitOverride`, `noFallthroughCasesInSwitch` all on. **No `any`** — model
  the types (e.g. `e.store.get<string>(...)`, `e.store.get<Record<string,string>>(...)`).
  `noUncheckedIndexedAccess` means a map/array index is `T | undefined` — handle
  the `undefined` (this is exactly the AC-7 missing-entry path).
- **Zero runtime deps except `jiti`.** Pure Node only; no npm additions, no SDK.
  The optional sub-call uses the existing provider via `e.agent.providers.get()`
  + `provider.stream(...)` — the global `fetch` plumbing already in place.
- **Tests use `node:test` via `tsx`, fully offline** against `MockProvider`. No
  network, no `ANTHROPIC_API_KEY`.
- **Capabilities are the security vocabulary.** This extension declares **no
  capability** — the heuristic reads only the transcript it is already handed, and
  the optional sub-call is capability-free and recursion-safe (design D2/D5).
- **Kill-switch env var** (`EAGENT_ROUTING=off`) and a **never-throw dispose
  loop** are mandatory, matching `recovery`/`risk-guard`/`cost`.

`README.md`. No `BUILTIN_EXTENSIONS` line, no inventory line, no count bump. Tests
must **not** depend on the extension being in `BUILTIN_EXTENSIONS` — load via
