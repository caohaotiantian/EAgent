Design Key Design Decisions carried into implementation: **D1** (new extension,
not a `memory` change), **D2** (the `transformContext` filter seam, `agent.ts:247`),
**D3** (backward walk; protect until 2 `user` messages seen — increment `turns`
*before* the `turns < 2` guard so eligibility begins at the 2nd-most-recent
`user` message; stop at `meta?.kind === "summary"`; the `compacted`-flag break is
not ported — stateless filter), **D4** (two-gate budget: keep while cumulative
`total <= PRUNE_PROTECT`, the crossing block and older are candidates, truncate
only if `pruned > PRUNE_MINIMUM`; constants 40_000 / 20_000 tokens, 2_000 chars),
**D5** (`est(s) = Math.max(0, Math.round(s.length / 4))`), **D6** (truncate
oversized candidates to head + marker; never rewrite a block already `<= cap`),
**D7** (register after `memory`).

### Phase 1 — the `prune` extension

**Entry condition:** baseline green — `npm test` `# fail 0` (307 pass on this
branch), `npm run typecheck` exit 0, clean tree.

**Design references:** `docs/design/2026-06-20-prune.md` §2 (Deliverables), §4
D1–D7 (lines 66–175), §5 (Dependencies, lines 177–192), §7 AC 1–10
(lines 229–283), §8 (Risks/Rollback).

**Key implementation shape (so a fresh agent builds it the same way):**
`src/extensions/prune.ts` exports a **pure, synchronous** function
`export function pruneMessages(messages: Message[]): Message[]` and a default
`activate(e: ExtensionAPI): void` that registers exactly one hook —
`e.hook("transformContext", (messages) => pruneMessages(messages))` — and nothing
else (no tool, no command). Exporting the pure function is what makes AC-8b
(synchronous, provider-free hot path) and the boundary ACs directly testable
without the hook bus. `pruneMessages` reads `process.env.EAGENT_PRUNE` itself
(AC-9). Mirror `memory.ts` for the `ExtensionAPI`/`e.hook` shape and the
"return a new array, never mutate the input" contract.

**Task list (TDD order — test tasks first):**

- **T1 (test): the pure-function invariants** in `test/prune.test.ts`. Import
  `{ pruneMessages }` from `../src/extensions/prune.js`. Build fixtures with two
  local helpers: `userMsg(s)` → `text("user", s)`; `assistantMsg(s)` →
  `text("assistant", s)`; and `toolMsg(id, n)` →
  `{ role: "tool", content: [{ type: "tool_result", toolCallId: id, content:
  "x".repeat(n) }] }` (build the `Message` via the typed literal; `n` is a
  **character** count, so `est = round(n/4)` tokens). Each test asserts the
  business invariant (*the model sees a token-bounded context: old, oversized
  tool outputs are trimmed; recent and in-budget outputs and the durable
  transcript are never touched*):
  - **AC-2 (no-op below budget):** a transcript with ≥3 user turns whose single
    eligible `tool_result` is `4*40000` chars (40000 tok, `total=40000 <= 40000`
    → kept). Assert every returned `tool_result.content` is unchanged (compare to
    the input lengths/strings).
  - **AC-3 (prune over budget):** eligible region (older than the 2nd-most-recent
    user message) holds, **newest→oldest**, `toolMsg("A", 4*30000)`,
    `toolMsg("B", 4*8000)`, `toolMsg("C", 4*8000)`, `toolMsg("D", 4*8000)`,
    `toolMsg("E", 4*8000)` (lay them out chronologically so A is the newest
    eligible — i.e. the one nearest the recency boundary — and E the oldest).
    Then 2 user turns after them form the protected window. Assert: A and B
    `content` unchanged (length 120000 and 32000); C, D, E each have
    `content.length <= TOOL_OUTPUT_MAX_CHARS + markerLen` and include the marker
    substring (e.g. `/pruned \d+ chars/`). (Trace: totals 30000/38000 kept,
    46000/54000/62000 pruned; `pruned=24000 > 20000`.)
  - **AC-4 (recency protection):** identical eligible region as AC-3 (so the run
    is over budget) **plus** a `toolMsg("R", 4*60000)` placed **after** the
    2nd-most-recent user message (inside the protected window). Assert `R`'s
    `content` is unchanged (length 240000), even though it is the largest output.
  - **AC-5 (summary boundary):** place a summary message
    `{ role: "system", content: [text...], meta: { kind: "summary" } }`
    mid-list, with over-budget oversized `toolMsg`s **at and before** it (older).
    Assert none of those at-or-before-summary outputs is truncated (walk halts).
    Put one over-budget eligible region *after* the summary (newer) only if also
    asserting it is unaffected by the stop; keep the core assertion on the
    at/before-summary blocks.
  - **AC-6 (below-minimum no-op):** eligible region = `toolMsg("H", 4*38000)`
    (kept, total 38000) then one older `toolMsg("X", 4*5000)` (crossing,
    total 43000 > 40000, `pruned=5000`). Since `5000` is not `> 20000`, assert
    every `content` unchanged.
  - **AC-7 (transcript purity):** run AC-3's over-budget input through
    `pruneMessages`; assert the **input** array, each input `Message`, and each
    input `tool_result.content` string are byte-for-byte unchanged afterwards
    (the function returned a new array with new block objects). Assert the result
    is a different array reference from the input.
  - **AC-8b (synchronous hot path):** `const r = pruneMessages(msgs);` then
    `assert.ok(Array.isArray(r))` and
    `assert.equal(typeof (r as { then?: unknown }).then, "undefined")` — the pure
    function returns a plain array synchronously, never a thenable.
  - **AC-9 (kill switch):** set `process.env.EAGENT_PRUNE = "off"` (restore in
    `finally`); AC-3's over-budget input is returned with every `content`
    unchanged.
  Watch fail (module absent).

- **T2 (impl): the extension** in `src/extensions/prune.ts`:
  - Constants: `const PRUNE_PROTECT = 40_000;` `const PRUNE_MINIMUM = 20_000;`
    `const TOOL_OUTPUT_MAX_CHARS = 2_000;` (token-denominated except the char cap).
  - `function est(s: string): number { return Math.max(0, Math.round(s.length / 4)); }`
  - `export function pruneMessages(messages: Message[]): Message[]`:
    1. If `process.env.EAGENT_PRUNE === "off"` return `messages` unchanged (D-rollback / AC-9).
    2. First backward pass to collect prune targets: iterate `for (let i =
       messages.length - 1; i >= 0; i--)`, keep `let turns = 0`, `let total = 0`,
       `let pruned = 0`, and `const targets = new Set<ToolResultBlock>()`. For each
       message: if `m.role === "user"` increment `turns`; if `m.meta?.kind ===
       "summary"` **break**; if `turns < 2` `continue` (protected recency window).
       Otherwise, for each block in `m.content` with `block.type ===
       "tool_result"`: `total += est(block.content)`; if `total <= PRUNE_PROTECT`
       `continue` (kept); else this is a candidate — `pruned += est(block.content)`
       and, **only if** `block.content.length > TOOL_OUTPUT_MAX_CHARS`, add it to
       `targets` (D6: never rewrite an already-small block).
    3. If `pruned <= PRUNE_MINIMUM` or `targets.size === 0`, return `messages`
       unchanged (no-op fast path — AC-2, AC-6).
    4. Otherwise build and return a **new** array: map each message to a new
       message; if any of its `tool_result` blocks is in `targets`, produce a new
       `content` array where those blocks are replaced by
       `{ ...block, content: truncate(block.content) }` and other blocks/messages
       are reused by reference (purity holds because we never mutate — AC-7).
       `truncate(s)` = `s.slice(0, TOOL_OUTPUT_MAX_CHARS) + "\n… [pruned " +
       (s.length - TOOL_OUTPUT_MAX_CHARS) + " chars to free context]"`.
  - `export default function activate(e: ExtensionAPI): void {
    e.hook("transformContext", (messages) => pruneMessages(messages)); }`.
  Make T1 green.

- **T3 (test): registration + provider-free, through the harness** in
  `test/prune.test.ts`:
  - **AC-1 (registration, measured):** `const h = makeHarness();` snapshot
    `h.agent.tools.list().length`, `h.commands.list().length`, and
    `h.agent.hooks.listenerCount("transformContext")`; `await h.host.use("prune",
    prune)`; assert tools-length and commands-length are **unchanged** and the
    `transformContext` listener count increased by **exactly 1**.
  - **AC-8a (provider-free under a real turn):** subclass the mock to count
    streams — `class Counting extends MockProvider { calls = 0; async
    *stream(req) { this.calls++; yield* super.stream(req); } }`. Build

    `Counting` provider as the default (`const c = new Counting([{ text: "done"
    }]); h.agent.providers.register(c, { default: true });`), `await h.host.use(
    "prune", prune)`, seed an over-budget transcript via `h.agent.load([...])`
    (the AC-3 shape), then `await h.agent.run("go")`. Assert `c.calls === 1`
    (one turn, **zero** extra provider round-trips — `prune` never summarizes).
  Watch the new ones fail until T2 + wiring land.
