## 3 · Decisions taken without the user this wave, still in force

- **600 seconds, and it lives in the DEPLOYMENT rather than the graph.** `cli.ts:1193`
  `STRANDED_LEASE_MS = 600_000`, passed at `cli.ts:1829` by `openWorkspace` to
  `new InProcessScheduler({strandedLeaseMs})`. It could NOT go in `compile.ts`: `NodePlan.timeoutMs`
  is what `#withNodeDeadline` ENFORCES on a live body, so a `human_gate` expiring because nobody
  wrote a number would be oversight failing OPEN. A recovery bound and an enforcement bound are two
  questions, and `select` aborts nothing, so only the first is asked. Unset stays exactly today's
  behaviour, so no embedder's live `subgraph` becomes reclaimable because of a constant chosen here.
- **A `subgraph` lease legitimately spanning more than 600 s is the accepted price**, recorded at the
  predicate (`run/scheduler.ts:231`) rather than dodged. Excluding `subgraph` was considered and
  costs more than it saves, because a plane is likeliest to die DURING a long child run. Reaching a
  live peer's child needs TWO independent bounds lapsed — the parent's lease past this one and the
  child's own task past its own compiled deadline. And **the parent's fencing token does not cover
  the child**: the store's compare-and-swap is per chain, so what it refuses is the loser's
  parent-side commit.
- **`run`, `resume` and `serve` get the scheduler; `replay` does not**, and the guarantee is the
  conjunction of three hand-built literals rather than one refusal — `replayRun` SPREADS its
  caller's `engine` options, so a `scheduler` in them would be inherited object and all. The three:
  `case "replay"` in `cli.ts`, `agent.ts`'s `engineOptions`, and `evolution/gate.ts`'s `replayRun`
  forwarding whatever its caller gave. A fourth site that spread `ws.engine`'s options would hand a
  replay this scheduler.
- **The scheduler's `#handedOut` set comes back EMPTY at a boot, and that is the permissive
  direction** — every lease then looks like a predecessor's, which is what it is. It is subtractive
  only, so no lost value can manufacture a false "dead", and it is therefore NOT a tenth member of
  the journal-violation class. `cli.ts`'s container census gains member 12 saying so, plus what that
  member exposes about the census's own method: it searches container LITERALS and would not have
  found a constructed object holding private state.
- **`NOT_ABSORBED_AS_SKIP` is `RUN_FATAL_CODES` ∪ {`E_HUMAN_APPROVAL_REQUIRED`,
  `E_OVERSIGHT_LOOSENED`}, and the two extra members are the decision.**
  `E_HUMAN_APPROVAL_REQUIRED` is deliberately outside `RUN_FATAL_CODES` so a run continues and the
  ask can be made elsewhere — a predicate reusing that set alone would relabel a branch a person
  actively REJECTED. `E_OVERSIGHT_LOOSENED` is `compileMutation`'s GRAPH014 refusal and is excluded
  FAIL-CLOSED, because the path is real by reading while a mutation that actually trips it was not
  constructed. `server/layout.ts`'s `STATE_PRIORITY` ranks `failed` first and `skipped` sixth, so
  relabelling either would drop it below five other states in the one view whose job is to show a
  person the worst thing in a collapsed fan-out. Oversight only tightens. The auditor cannot import
  the executor, so the set exists twice and `registries.test.ts` censuses the two copies.
- **The replay-compatibility break was taken deliberately.** A divergence NAMING both states is
  better than the alternative it replaced: every branch a join absorbed stayed `failed` inside a run
  reporting **succeeded**.
- **`refactor:` was used for two kernel-vocabulary deletions**, `c816826` and `fa25cc7`, and both
  commit bodies DISCLOSE it rather than leaving it to a trailer that does not exist.
  `check-kernel.mjs` frees every subject but `feat`, and CLAUDE.md names that as the blind spot the
  guard cannot see; the ledger for 53 → 52 → 51 therefore lives in `test/journal/store.test.ts`,
  **re-derived from git rather than read forward from the comment it replaced** — reading it forward
  produced a plausible `54 → 53` that never happened, and a reviewer caught the invented row before
  it landed.
- **A realm `Date` throws `E_EFFECT_UNRECORDED` until a call seeds it.** The zero-arg forms read a
  per-call cell rather than a definition-time value, closing the same definition-time-IIFE window
  `DENY_UNSEEDED` already closes for `Math.random`; explicit-argument forms forward to the real
  `Date` through `Reflect.construct`, untouched. The installer builds the constructor ENTIRELY
  IN-CONTEXT, never as a host closure, which would itself carry the host `Function` on its prototype
  chain. `resources/functions.ts` is the only opt-in caller; hook realms are unchanged.
- **The port chose a triage workflow over the two alternatives**, recorded in
  `docs/workflow-port-2026-09-09.md` §1: a diff-review/PR-description pipeline duplicates
  `self-review.json` and has nothing but a model call in it, and changelog-to-release-notes is the
  same problem smaller. The choice was for something that runs offline AND MEANS something offline —
  a failing test's root cause is read off its error signature, so there was never a model in it.
  The cost is named: it exercises nothing about providers, budgets, retries, fallback chains,
  `subgraph`, `router`, bounded loops or compensation edges.
